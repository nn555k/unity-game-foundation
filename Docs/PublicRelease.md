# v0.6.0 公开版本与迁移

## 保留与移除

公开版本保留 Core、Save、HotUpdate、YooAsset Backend、SDK、UI、Setup 七个包，以及 AGENTS、AI Skills、Feature Spec、目录规范、Resources 约定和自动接入/校验脚本。

两套设计下载与同步工具及其支持代码、资源、依赖、安装菜单、专属就绪检查和测试已从发布内容移除。通用的 `FigmaPrefabNormalizer`、`UiPrefabValidator`、`UiPrefabConventionProfile` 和导入后规范化 Skill 继续提供，不依赖下载插件。没有设计工具也能制作和校验普通 uGUI 预制体。

本版本不改变通用运行时 API、存档格式、玩家数据位置或资源加载方式，不搬迁消费项目资源，也不删除消费项目现有插件。商品链接不属于框架能力，不随公开版本分发。QFramework 等保留依赖的版权与许可声明继续保留。

## 历史隔离

原仓库改名为 `nn555k/unity-game-foundation-private-archive-20261009` 并保持私有，保存旧源码、提交、分支和发布版本。公开仓库 `nn555k/unity-game-foundation` 从干净历史开始，只发布 `v0.6.0` 及后续版本，不推送旧 Git 对象、标签、Actions 日志或测试录像。

## 消费项目升级

- 新项目使用公开仓库的 `v0.6.0` 安装入口；框架源码的访问不需要私有仓库凭据。使用授权仍以根目录 LICENSE 为准。
- 已使用旧标签的项目，不要只更新分支或清空包缓存。要保留旧版本，请把旧 Git URL 的仓库名改为私有备份仓库名，保留原包路径与标签，并确保访问权限。
- 要升级基础框架，将七个受支持包统一改为公开仓库的 `v0.6.0`。先提交项目当前状态，再验证编译、UI、存档和本项目的适配器。
- 旧设计工具包不在公开仓库中。保留它时使用有权限的私有来源，或由开发者另行接入独立工具；不能把旧工具包路径改为 `#v0.6.0`。
- 不要把旧本地克隆的历史或所有标签推送回公开仓库。使用新克隆；历史备份只连接私有仓库。
